## 重要说明

这些截图是在 **HSV 颜色阈值（演示预设值）** 下产生的。该阈值没有针对真实果实标定，因此其中部分记录实际是对室内环境（人脸、桌面、背景物体）的误判，被系统当成了水果。

这正好说明本项目当前的识别方式：

- 用的是 **OpenCV 的 HSV 色块分割 + 面积/置信度过滤**，不是神经网络
- `camera_service.py` 里的 `FRUITS` 预设（apple / lemon / mango / peach / pear）是演示值
- 真实场景使用前必须重新标定阈值，或改用训练好的 TFLite 模型

如果要做实验五的神经网络识别，这些图不能作为数据集标签使用。
