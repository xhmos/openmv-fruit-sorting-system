从零搭建与服务器部署指南Step-by-Step Setup & Server Deployment Guide

面向零基础同学：按「环境准备 → 软件安装 → 本地试运行 → 部署上线」的逻辑顺序，每一步写清具体做什么。 For beginners: follow the logical order Environment → Software → Local run → Deployment; each step explains exactly what to do.

1.1

准备本地电脑 Local computer必需 Required

具体做：选一台能编写代码、本地调试的电脑，Windows / macOS / Linux 均可，本指南以 Windows 为例。

Do: pick a PC for coding and debugging; Windows / macOS / Linux all work; this guide uses Windows.

  • 确认系统能正常联网、可安装软件 — ensure network and install permission
  • 预留足够磁盘空间存放代码与依赖 — reserve disk space for code and dependencies
✅ 产出：一台可用的本地开发机 · Result: a working local dev machine
1.2

准备云服务器 Cloud server必需 Required

具体做：购买一台轻量应用服务器（腾讯云 / 阿里云等），操作系统选 Ubuntu 22.04，配置 2 核 4G 以上；购买后记下公网 IP、登录账号和密码。

Do: buy a lightweight server (Tencent Cloud / Aliyun), choose Ubuntu 22.04, ≥2 vCPU / 4GB RAM; record the public IP, login user and password.

  • 在控制台查看实例的公网 IP 地址 — copy the public IP from the console
  • 设置好服务器登录密码并妥善保存 — set and save the login password
✅ 产出：一台可远程登录的公网服务器 · Result: a reachable public server
1.3

确认远程连接通道 Remote access channel必需 Required

具体做：确认本地能通过 SSH（22 端口）连上服务器，后续用命令行或网页终端在服务器上操作。

Do: confirm your PC can reach the server over SSH port 22; you will operate the server via command line or web terminal.

  • 在云控制台防火墙放行 SSH（22）端口 — allow SSH port 22 in the firewall
  • 用终端工具测试账号密码能否登录 — test login with user and password
1.4

准备 OpenMV 板与摄像头 OpenMV board & camera可选 Optional

具体做：没有板子时，可用电脑摄像头或模拟设备完成演示；要接真实硬件时再准备 OpenMV H7 / RT1062 开发板及配套摄像头。

Do: demo with a PC camera or simulated device without a board; only prepare an OpenMV H7 / RT1062 board and camera when using real hardware.

🏗️ 架构总览：前端 Vue 负责页面，后端 Flask 负责接口，MySQL 存数据，OpenMV / 摄像头采集画面。 Overview: Vue frontend renders pages, Flask backend serves APIs, MySQL stores data, OpenMV / camera captures images.
组件 Component技术栈 Tech作用 Role
前端 FrontendVue 3 + Vite + Element Plus + ECharts页面与看板展示Pages & dashboard
后端 BackendFlask + Flask-SocketIO + OpenCV接口、识别、实时推送APIs, detection, realtime push
数据库 DatabaseMySQL 8用户、记录、设置等数据Users, records, settings
设备 DeviceOpenMV 脚本 / PC 摄像头采集并上报画面Capture and report images
2.1

安装 Python（后端运行环境）Python for backend必需 Required

具体做：安装 Python 3.12，安装时勾选「Add Python to PATH」；后端用 Python 提供接口服务。

Do: install Python 3.12, tick "Add Python to PATH"; the backend runs in Python to serve APIs.

  • 从官网下载 Python 3.12 安装包并安装 — download and install Python 3.12
  • 命令行输入 python --version 确认版本 — verify with python --version
2.2

安装 Node.js（前端打包环境）Node.js for frontend必需 Required

具体做：安装 Node.js 20 LTS，用于安装前端依赖并把 Vue 页面打包成静态文件。

Do: install Node.js 20 LTS to install frontend dependencies and build Vue pages into static files.

  • 下载安装 Node.js 20 长期支持版 — install Node.js 20 LTS
  • 命令行输入 node -v 确认安装成功 — verify with node -v
2.3

安装 MySQL 数据库 MySQL database必需 Required

具体做：安装 MySQL 8 并设置 root 密码；部署时在库中创建业务库（本项目库名 openmv_ai）和业务账号。数据库只在本机 / 内网使用，不对公网开放。

Do: install MySQL 8, set the root password; create the business database (openmv_ai) and a business user. Keep the DB local / internal, not public.

  • 安装 MySQL 8 服务并设好 root 密码 — install MySQL 8 and set root password
  • 创建业务库 openmv_ai，字符集 utf8mb4 — create database openmv_ai, utf8mb4
# 创建业务库（示例）/ Create database (example)
CREATE DATABASE openmv_ai DEFAULT CHARACTER SET utf8mb4;
2.4

安装后端依赖包 Backend dependencies必需 Required

具体做：进入后端目录，新建虚拟环境，按 requirements.txt 安装 Flask、SocketIO、OpenCV 等依赖。

Do: enter the backend folder, create a virtual environment and install Flask, SocketIO, OpenCV etc. from requirements.txt.

# Windows 示例 / Windows example
cd backend
python -m venv venv
venv\Scripts\pip install -r requirements.txt
2.5

安装前端依赖包 Frontend dependencies必需 Required

具体做：进入前端目录，用 npm 安装 Vue、Element Plus、ECharts 等依赖。

Do: enter the frontend folder and install Vue, Element Plus, ECharts etc. with npm.

cd frontend
npm install
2.6

安装 Docker（服务器打包运行用）Docker for server可选 Optional

具体做：用容器方式部署时，在服务器上安装 Docker 和 Compose 插件；本地手动调试可以不装。

Do: install Docker and the Compose plugin on the server for container deployment; not needed for local manual debugging.

2.7

安装 TensorFlow 训练环境 TensorFlow training env可选 Optional

具体做：只有需要本地训练 / 转换神经网络 TFLite 模型时才安装；纯演示、分拣、记录查看不需要。

Do: install only when training or converting a TFLite model locally; not required for demo, sorting or record viewing.

⚠️ 提示：Python、Node、MySQL 版本不要随意更换，版本不匹配是安装报错的主要原因。 Tip: keep the Python / Node / MySQL versions close to the guide; version mismatch is the main cause of install errors.
3.1

配置环境变量 Configure env variables必需 Required

具体做：在后端目录把 .env.example 复制为 .env，填写数据库账号、密码、库名、密钥和设备令牌。

Do: copy .env.example to .env in the backend folder; fill in DB user, password, database name, secret key and device token.

3.2

启动后端 Start the backend必需 Required

具体做：运行后端服务，默认监听 5000 端口；访问健康检查 /api/health 返回 ok 即正常。

Do: start the backend on port 5000; the health check /api/health returning ok means it works.

venv\Scripts\python app.py
3.3

启动前端 Start the frontend必需 Required

具体做：另开一个终端启动前端开发服务器，浏览器打开提示的本地地址即可看到登录页。

Do: open another terminal, start the frontend dev server; open the local address shown to see the login page.

npm run dev
3.4

登录并核对功能 Login & check features必需 Required

具体做：用管理员账号登录，进入看板、设备、记录、设置页面，确认画面、记录、统计正常显示。

Do: login as admin, open dashboard, device, records and settings; confirm images, records and statistics display correctly.

  • 核对实时画面、统计卡片、趋势图 — check live image, stats cards, charts
  • 核对分拣记录列表与图片查看 — check record list and image viewing
4.1

上传项目代码 Upload project code必需 Required

具体做：把后端、前端、配置文件上传到服务器项目目录；venv、node_modules、dist、训练缓存等可重建的大目录不用上传。

Do: upload backend, frontend and config files to the server project folder. Skip rebuildable heavy folders like venv, node_modules, dist and training caches.

4.2

配置服务器环境变量 Configure server env必需 Required

具体做：在服务器项目根目录复制并填写 .env：数据库用户、密码、库名要和服务器 MySQL 一致。

Do: copy and fill in .env at the server project root; DB user, password and name must match the server MySQL.

cp .env.docker .env
nano .env
4.3

构建并启动服务 Build & start services必需 Required

具体做：用 Docker Compose 一键构建并后台启动前后端容器；后端由 gunicorn + eventlet 运行，支持实时推送。

Do: build and start frontend + backend containers in the background with Docker Compose; backend runs gunicorn + eventlet for realtime push.

# 构建并后台启动 / Build and start in background
sudo docker compose up -d --build

# 查看状态 / Check status
sudo docker compose ps

# 查看后端日志 / Backend logs
sudo docker compose logs -f backend
4.4

放行公网端口 Open the public port必需 Required

具体做：在云服务器控制台防火墙 / 安全组放行网站入口端口（本项目 4173）；数据库 3306 不要对外放行。

Do: in the cloud console firewall / security group, open the website entry port (4173). Do NOT expose MySQL 3306.

🌐 前端 Nginx
  • 对外 4173 → 容器 80 · Public 4173 → container 80
  • 网站唯一入口 · Only public entry
🔒 后端 / 数据库
  • 后端 5000 仅容器内网 · Backend 5000 internal only
  • MySQL 3306 不对公网 · MySQL 3306 not public
4.5

公网访问验证 Verify public access必需 Required

具体做：浏览器打开 http://服务器公网IP:4173/#/login，能看到登录页并成功登录即部署成功；健康检查返回 {"code":0,"msg":"ok"} 表示后端正常。

Do: open http://SERVER_IP:4173/#/login; seeing the login page and logging in means success; health check {"code":0,"msg":"ok"} means backend is healthy.

✅ 产出：公网可访问的在线系统 · Result: a live system reachable from the public internet
🔧 常用运维：停止 docker compose down，重启 docker compose restart，改代码后重新构建 docker compose up -d --build。 Ops: stop docker compose down, restart docker compose restart, rebuild after change docker compose up -d --build.
A1

内网穿透临时公网地址 Temporary tunnel可选 Optional

具体做：不买服务器时，可用 cpolar / Cloudflare 隧道把本地服务临时暴露成公网链接做演示；关闭后地址失效。

Do: without a server, use a cpolar / Cloudflare tunnel to expose the local service as a temporary public link; the link dies when closed.

A2

模型训练与转换 Model training & conversion可选 Optional

具体做：在 train/ 目录采集数据集、训练轻量 CNN、量化导出 TFLite，供 OpenMV 板端分类使用。

Do: in train/, collect a dataset, train a lightweight CNN, quantize and export TFLite for OpenMV board classification.

A3

手机端 App 打包 Mobile app build可选 Optional

具体做：项目附带 Flutter 手机端，需要时用 Flutter 打包成 APK 安装到手机查看。

Do: the project includes a Flutter client; build it into an APK with Flutter when you want to view it on a phone.

A4

开机自启与进程守护 Autostart & process guard可选 Optional

具体做：生产环境配置开机自动拉起容器、崩溃自动重启，避免服务器重启后服务离线。

Do: configure autostart and auto-restart on crash so the service stays online after a reboot.

A5

域名与 HTTPS 证书 Domain & HTTPS可选 Optional

具体做：有域名后绑定公网 IP 并配置 HTTPS 证书，让网址更好记、访问更安全。

Do: with a domain, bind it to the public IP and set up an HTTPS certificate for a memorable, secure URL.
